API de Produtos

Sistema de gerenciamento de produtos em tempo real

Status do Servidor: Verificando conexao...

1 - Listar Todos os Produtos

Endpoint: GET /produtos | Parametros: Nenhum | Status Esperado: 200 OK

2 - Filtrar por Categoria (req.query)

Endpoint: GET /produtos/filtrar?categoria=X | Parametro: req.query | Status Esperado: 200 OK

req.query: Captura parametros opcionais da URL como chave-valor (?categoria=Eletronicos). Util para filtros, buscas e parametros opcionais.

3 - Buscar por ID (req.params)

Endpoint: GET /produtos/:id | Parametro: req.params | Status Esperado: 200 OK ou 404 Not Found

req.params: Captura valores obrigatorios na rota (/produtos/:id a req.params.id). Usado para identificadores especificos.

4 - Cadastrar Novo Produto (req.body)

Endpoint: POST /produtos | Parametro: req.body | Status Esperado: 201 Created

req.body: Captura dados enviados no corpo da requisicao (JSON do formulario). Requer middleware express.json() para funcionar.

5 - Remover Produto (DELETE)

Endpoint: DELETE /produtos/:id | Parametro: req.params | Status Esperado: 200 OK ou 404 Not Found
